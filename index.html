React + WordPress REST API, from Zero

ForumWP React Examples

241 examples from the course, each a single HTML page that runs as it is. Press Run, or open one in a sandbox to change the code and see what happens.

  • Run it anywhereEach page loads React and WordPress's own components from a CDN and compiles the JSX in your browser. No install, no build.
  • Look at the consoleConsole output also appears under the example. React's development warnings are on, so you see the same messages the book quotes.
  • Fake REST APIExamples marked so answer the Chapter 14 routes from memory. In the console, try fakeApi.delay = 2000 or fakeApi.fail = true.
  • PHP is not hereThe PHP in the book needs WordPress itself. Use your local site or WordPress Playground for those.
